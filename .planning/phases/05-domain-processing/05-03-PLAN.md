PolicyResult Pydantic v2 model (inline in policy_engine.py):
```python
class PolicyResult(BaseModel):
    triggered_rules: list[str] = Field(default_factory=list)
    rule_details: list[dict] = Field(default_factory=list)
    escalate: bool = False
    alert_pm: bool = False
```

evaluate_policies(event: EnrichedEvent, config: EventTypeConfig) -> PolicyResult:
1. Load rules YAML from config.rules_file (Path relative to project root = Path(config.rules_file))
2. rules = yaml_data.get("rules", [])
3. For each rule, call _evaluate_condition(rule["condition"], event) → bool
4. If True: add rule_id to triggered_rules, full rule dict to rule_details
5. escalate = any triggered rule has priority in ("critical",)
6. alert_pm = len(triggered_rules) > 0
7. Return PolicyResult(...)

_evaluate_condition(condition_str: str, event: EnrichedEvent) -> bool:
- Normalize: condition_str.strip()
- Split on " AND " → sub_conditions
- All sub_conditions must evaluate True (AND logic)
- For each sub_condition call _eval_sub(sub, event)
- If any raises, return False (safe default)

_eval_sub(sub: str, event: EnrichedEvent) -> bool:
Build an event_fields dict from event:
```python
event_fields = {
    "quantity": event.event.quantity or 0,
    "estimated_cost": event.event.estimated_cost or 0,
    "material_original": (event.event.material_original or "").lower(),
    "material_new": (event.event.material_new or "").lower(),
    "change_type": (event.event.change_type or "").lower(),
    "location": (event.event.location or "").lower(),
    "element_type": "window",      # inferred for demo; future: from event
    "material_category": "wood" if "wood" in (event.event.material_new or "").lower() else "other",
    "affects_load_bearing": False,  # future: from event
    "material_in_spec": True,       # future: from event
    "po_issued": False,
    "pm_decision": "",
    "units_occupied": False,
    "on_critical_path": False,
    "schedule_impact_days": 0,
    "floor_number": 3,              # inferred from location for demo
    "location_type": "exterior",
    "change_affects_unit_interior": False,
}
```
Parse operator: >, >=, <, <=, ==, !=, IN
For IN: check if event_fields[field] in ast.literal_eval(value_str) — ast.literal_eval is safe (no code execution)
For comparisons: cast both sides to float if possible, else lowercase string compare
Return False if field not in event_fields (unknown fields are safely skipped).

NOTE: ast.literal_eval is explicitly allowed (it parses Python literals only, not arbitrary code). Never use eval() or exec().
