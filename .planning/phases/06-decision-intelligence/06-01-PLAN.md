```python
Confidence scorer — DI-03.
Weighted 4-factor formula. No LLM calls. No config.settings import.

from typing import TYPE_CHECKING, Literal
from pydantic import BaseModel, ConfigDict

if TYPE_CHECKING:
    from src.system.domain_processing.processor import ProcessingResult
    from src.system.context.historical import HistoricalMatch

class ConfidenceResult(BaseModel):
    model_config = ConfigDict(str_strip_whitespace=True)
    score: float          # 0.0 to 100.0
    breakdown: dict       # {"data_clarity": float, "historical_match": float, "cost_acceptable": float, "no_red_flags": float}
    recommendation: Literal["accept", "review", "reject"]

def score_proposal(
    processing_result: "ProcessingResult",
    historical_matches: list["HistoricalMatch"],
) -> ConfidenceResult:
    ...
```

Formula (weights sum to 1.0):
- `data_clarity` (weight 0.30): `processing_result.event.event.confidence / 100.0` — maps NormalizedEvent.confidence (0-100 int) to 0-1
- `historical_match` (weight 0.25): `mean([m.similarity for m in historical_matches])` if matches else `0.0`
- `cost_acceptable` (weight 0.25): `0.0` if `estimated_cost` is not None and `estimated_cost > 50000`, else `1.0`
- `no_red_flags` (weight 0.20): `0.5` if `processing_result.policy_result.escalate_immediately` else `1.0`

`score = (data_clarity * 0.30 + historical_match * 0.25 + cost_acceptable * 0.25 + no_red_flags * 0.20) * 100`

No penalty multipliers. The formula is deterministic as written above.

Recommendation thresholds:
- score > 80 → "accept"
- 50 <= score <= 80 → "review"
- score < 50 → "reject"
