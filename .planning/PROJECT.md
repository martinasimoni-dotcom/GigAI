# PROJECT.md — GigAI

## Core Value

GigAI eliminates the manual coordination burden on construction project managers when material changes occur. A PM currently spends 3-5 hours manually tracking, emailing, scheduling, and updating drawings for every material change. GigAI reduces that to under 12 minutes by capturing changes from meeting transcripts and ACC, enriching them with project context, generating a complete coordinated proposal, and executing approved actions automatically.

## Problem Statement

Construction PMs spend 60-70% of coordination time on material changes:
- Manual transcription and tracking from meeting notes
- Contacting suppliers for quotes and availability
- Updating schedules and drawings manually
- Notifying multiple stakeholders across channels
- Following up on procurement and delivery

This causes 3-5 day delays in procurement, missed stakeholder notifications, and PM burnout.

## Solution

An event-driven AI pipeline:
1. Capture — Fireflies webhook, ACC webhook, Gmail polling, Calendar polling
2. Process — Haiku LLM normalizes and routes events
3. Enrich — ACC API + pgvector knowledge folder retrieval
4. Generate — Sonnet 4 generates email, task, calendar, drawing markup actions
5. Score — Weighted confidence score (>80% = recommend accept)
6. Present — PM reviews proposal in dashboard, one-click accept/reject
7. Execute — Action gateway fires all approved actions via external APIs
8. Learn — Feedback stored, embeddings updated

## Constraints

- Python 3.11 + FastAPI (async-native)
- LLMs: Claude Sonnet 4 (proposals), Claude Haiku 4.5 (normalization/routing)
- Embeddings: Voyage-3 (1024-dim)
- Database: PostgreSQL 15 + pgvector
- Event bus: Google Cloud Pub/Sub
- No fine-tuned models, no spaCy, no OpenAI, no Claude Vision
- Human-in-the-loop: every proposal requires PM approval
- All secrets in .env, never hardcoded

## Success Targets

- 80% reduction in PM coordination time (4 hours → 48 minutes per change)
- >90% accuracy on high-confidence (>80%) proposals
- <5 minutes from event detection to proposal generation
- 75% PM acceptance rate within 3 months
- $50K+ saved per project in PM time and procurement speed

## Users

- Primary: Project Manager (Sarah) — reviews and approves proposals
- Secondary: Procurement Officer (Mike) — receives tasks generated by system
- Tertiary: Suppliers (Jane) — receives automated quote request emails
