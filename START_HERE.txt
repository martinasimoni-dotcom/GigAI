This is the canonical entry document for the current workspace.

Run the current app
-------------------

1. Run one main launcher file from workspace root:
   .\.venv\Scripts\python.exe .\RUN_GIGAI.py --mode all --reload --stop-existing

   Or (if Python is on PATH):
   python .\RUN_GIGAI.py --mode all --reload --stop-existing

   Or double-click:
   RUN_GIGAI.bat

2. Open:
   http://localhost:3000

3. Optional single-service modes:
   python .\RUN_GIGAI.py --mode backend --reload --stop-existing
   python .\RUN_GIGAI.py --mode frontend
